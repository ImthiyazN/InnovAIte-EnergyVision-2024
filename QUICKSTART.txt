# ⚡ Energy Tracker - Quick Reference

## 🎯 3-Minute Quick Start

### Quick Start (No npm required)
```bash
cd /Users/aaquib/Developer/innovate_2026
# (Optional) Create config.js from config.example.js and add your OpenAI key:
# echo "window.OPENAI_API_KEY='sk-your_key'" > config.js
# Start a simple static server (Python built-in):
python -m http.server 8000
```

### Browser
Open: `http://localhost:8000` then visit the pages

## 📊 Usage Report Features

### Energy Graphs
- **30-Day Trend**: Shows your usage vs target
- **Today's Hourly**: Actual vs AI projection
- **7-Day Forecast**: Next week prediction
- **AI Tips**: 3-4 personalized recommendations

### Target Setting
```
Enter number → Click "Set Target" → Track progress
```

### Rewards Earned
```
Less energy used → Earn points → Redeem gift card
```

### Gift Card Redemption
1. Choose store (Carrefour/Amazon/Noon/DEWA)
2. Enter amount
3. Click Redeem
4. Get code to use

### OpenAI API Key (client-side)
Create a `config.js` (copy from `config.example.js`) and add:
```javascript
window.OPENAI_API_KEY = 'sk-your_openai_key_here';
```
Warning: placing API keys in client-side code is insecure — only use for local testing.

### Charts blank
- Refresh page
- Check browser console (F12)
- Verify API running

## 🔗 Quick Checks

No backend required — data is generated locally. To check OpenAI connectivity (if you created `config.js`):

```bash
curl -s -X POST https://api.openai.com/v1/chat/completions \
	-H "Authorization: Bearer $OPENAI_API_KEY" \
	-H "Content-Type: application/json" \
	-d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"hello"}]}'
```
