# Project README (InnovAIte 2024)

## EnergyVision - Community Energy Consumption & Conservation Tracker

An AI-enabled web application prototype developed during the **UAE InnovAIte Hackathon (2024)**. EnergyVision enables households to monitor real-time energy usage, optimize consumption patterns, and benchmark their sustainability performance against neighboring communities.

## Key Features

* **Real-Time Energy Monitoring:** Visualizes live electricity and energy consumption metrics for individual households.
* **Neighborhood Benchmarking:** Compares household energy efficiency scores against nearby district and community averages to encourage sustainable habits.
* **Conservation Insights:** Identifies peak usage times and suggests actionable steps to reduce energy waste and lower power bills.
* **AI-Driven Consumption Trends:** Analyzes historic usage patterns to forecast future energy demands and highlight saving opportunities.

---

## Tech Stack & Tools

* **Frontend:** HTML5, CSS3, JavaScript
* **Data Visualization:** Chart.js / D3.js (Interactive usage graphs)
* **Backend Logic:** Python / Node.js
* **Version Control:** Git & GitHub

---

## Project Structure

* `index.html` - Main dashboard interface showing energy usage graphs and neighborhood leaderboard.
* `style.css` - UI layout, responsive styling, and modern dashboard theme.
* `app.js` - Application logic handling user inputs, data processing, and neighborhood efficiency calculations.
* `data/` - Datasets containing simulated household consumption metrics and neighborhood benchmarks.
